# Smart Study Planner 📚

A Python-based application designed to help students organise subjects, manage study tasks and plan their daily study schedules.

## 🎯 Project Objectives

* Organise subjects and study materials.
* Create and manage study tasks.
* Set deadlines and priorities.
* Build a structured study schedule.
* Track study progress.

## 🛠️ Technology Stack

* Python
* SQLite (planned for data storage)
* Tkinter (planned for graphical interface)

## 🚀 Planned Features

* Add, edit and delete subjects.
* Add tasks with deadlines.
* Mark tasks as completed.
* View pending and completed tasks.
* Generate daily study plans.
